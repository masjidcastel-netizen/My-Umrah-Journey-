## Known gaps / placeholders (be aware)
- **Models**: everything is procedural primitives. Masjid Castel is a stylised placeholder, not an accurate reproduction. Characters are capsule people, not rigged humanoids.
- **Scenes**: one scene (`MauritiusCastel`) is generated by the editor tool on first open, not shipped as a .unity file. The world itself is built by code at load.
- **Audio**: one procedural engine loop only. No voice, music or ambience.
- **Arabic/Urdu**: strings exist but uGUI legacy Text does not shape/connect Arabic or Urdu letters and the built-in font lacks glyphs. Needs TextMeshPro + an RTL shaping solution + Arabic/Urdu fonts. Language buttons use Latin names for this reason.
- **Translations**: first drafts (Kreol, Arabic, Urdu, French) - need native-speaker review. No Islamic educational content has been written yet; all of it will need qualified Sunni scholarly review.
- **Not done in Milestone A**: swim button (swimming is automatic in water), character customisation UI, occlusion culling bake, Addressables, minimap, real map data, other towns, airport, Madinah, Makkah, Umrah, Hajj (all later phases).
- Runtime quality changes modify the URP asset in the Editor (they persist in the asset; revert with git/Setup).
- `Library/` is not included; first open re-imports everything.
